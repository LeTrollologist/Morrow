# Morrow v2.4.19

Security, soundness, runtime-diagnostics and release-gate release.

## Fixes

- **#4 — type-checker soundness.** Undefined types, incompatible call arguments,
  invalid `let` annotations/assignments, bad return expressions and missing returns
  are rejected. Diagnostics name the callee/function and expected/actual kinds.
- **#5 — region cleanup on every exit.** Return, `break` and `continue` now emit
  `morrow_region_exit` for every active region, innermost first, including nested
  regions. `morrow_region_live_count()` exposes runtime balance for tests.
- **#6 — controlled runtime diagnostics.** Unhandled effects print
  `Runtime error: unhandled effect <effect>::<op>`; division/modulo by zero prints
  `Runtime error: division by zero`; both exit with status 1.
- **#7 — command-injection fix.** Process spawning no longer uses `system()`.
  Windows uses `CreateProcessA`; POSIX uses `wordexp(WRDE_NOCMD)` +
  `posix_spawnp`. `forge` quotes output paths, so shell metacharacters are literal.
- **#8 — release runtime gate.** The release pipeline executes supported examples
  with expected exit codes, reports pass/fail/skip, and fails the release on a
  runtime mismatch. SQLite and interactive-server prerequisites are documented.
- **#9 — test integrity.** `assert_true` now exits the suite on failure; test and
  benchmark retries were removed; formatter tests compare the semantic token stream.
- **#11 — documentation/algorithm truth pass.** `let` mutability, narrowing,
  escape sequences, crypto/checksum claims, and SQL-builder safety claims match the
  implementation. FNV-1a and CRC-32 now produce standard vectors; `\0` is a real
  escape; the README headline example is compiled by the suite.
- **#13 — short-circuit `&&`/`||`.** Logical operators lower to explicit control
  flow; the right operand is not evaluated when the left determines the result.

## Verification

- `forge test`: 28 positive suites + 18 compile-fail suites.
- Self-hosting three-stage fixed point recorded in `releases/v2.4.19.json`.
- Supported examples executed by the release gate; build-only examples and their

- New regressions: process injection, region cleanup, runtime diagnostics,
  short-circuiting, standard hash/checksum vectors, README example.
