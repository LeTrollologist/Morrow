  **archived Stage-0 Rust** implementation, and that the Feature Status Matrix is the

## Stale artifacts removed

- **`bin/tgc_linux`** is gone. It was a Linux compiler binary from the Tungsten era
  that still answered `Forge 0.2.0`; it could not run on this host and no release ever
  shipped it.
- **`Dockerfile`** and **`docker-compose.yml`** are marked **UNMAINTAINED** with the
  reason stated in the file: they `COPY bin/tgc_linux` and invoke `./bin/mwc --target`,
  and container builds cannot bootstrap without a Linux Morrow seed binary, which is
  not published. They are kept for provenance, not as a supported path.
