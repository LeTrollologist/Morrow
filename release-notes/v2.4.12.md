# Morrow v2.4.12 — The corpus localises the loss instead of counting it

**Release date:** 2026-11-02
**Toolchain:** `forge 2.4.12 (morrow standalone 2026)`
**Self-hosting fixed point:** `F23E5B37C9ED0585AF7745EF9C3DAABF73C9AF1476E220657C17F1E2837E0517`
(stage2.ll == stage3.ll, stage2.exe == stage3.exe, 467968 bytes)

No compiler change. The diagnostic corpus grew from 6 to **13 cases** and now records an
expected **count per case** — because a total is not evidence, and an "ok" case can be
satisfied by not checking at all.

## Four areas, each with a positive and a negative

| Area | Positive | Negative |
|---|---|---|
| struct field | `String` field → `String` param: silent | `i64` field → `String` param: 1 finding |
| call result | `String`-returning call → `String` param: silent | `i64`-returning call → `String` param: 1 finding |
| collection accessor | `vec_get` → `i64` param: silent for the case | `vec_len` → `String` param: 1 finding |
| typed variable | `let s: String` → `String` param: silent | `let n: i64` → `String` param: 1 finding |

## What it localised

Field lookups, function returns and typed variables **already carry their kind**. The
aggregate count of 229 is dominated by collection/generic plumbing: `vec_get` returning `T`,
`hashmap_insert` taking a `String` key. That is **one** loss of information, not four — so
the next fix belongs in how `T`-typed callees report results, not in a rule that re-derives
kinds at every argument.

## Two counts per case, and why

The report carries no source positions, so it cannot say which file a finding came from —
and importing `std::collections` typechecks std's own calls. Each case therefore records:

- **own** — findings naming a callee declared in the case file;
- **baseline** — findings contributed by imported std at this version, *named exactly*
  (`want=String got=u8 :: hashmap_insert`), so a change in std is visible rather than
  absorbed into a count.

That baseline line is itself a finding about std worth keeping: `hashmap_insert`'s key
parameter is declared `String` and the inferred argument is `u8`.

## Enforcement

Untouched. Diagnostic stage only; experimental and default enforcement remain not-started,
gated on a corpus that is now broader but still far from complete.
